# UI Products

Módulo compartilhado de catálogo, produtos, categorias, insumos e vitrines do ERP.

O catálogo operacional do POS reutiliza `ProductsPage`. No modo `single-item`, a tela apresenta seleção unitária responsiva e usa exclusivamente as mídias cadastradas em `productFiles` e as cores do tema ativo.
